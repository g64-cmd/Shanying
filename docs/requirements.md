更新：2026-10-24。本页取代初始化时“电商不进入首期、搜索后置”的草案。当前只完成规范，未实现以下业务。

业务场景见 [define-shanying-platform](../openspec/changes/define-shanying-platform/proposal.md)：specs/ 为七个领域的可验收要求，design.md 为方案，tasks.md 为未完成实现任务。bootstrap-shanying-monorepo 只保留初始化历史，不代表当前产品范围。

## 目标及范围

实现 UGC 短视频 → 用户观看 → 商家广告投流 → 电商购物，连接用户、普通创作者、少量独立商家与平台。旧仓库补充细节，不作为架构或正确性依据。

| 领域 | 已确认范围 |
| --- | --- |
| 账号 | 邮箱注册验证、密码登录/找回、会话管理、资料、关注审批、移除粉丝、黑名单、私密账号 |
| 内容 | 上传处理发布、点赞评论收藏、公开/好友/仅自己可见、关注流、推荐流、视频及用户搜索 |
| 私聊 | 普通用户一对一；文字、图片、视频/商品/订单卡片、历史、未读、已读；单店一个客服入口 |
| 电商 | 独立商家、平台创建店铺、商品规格库存、商品/店铺搜索推荐、购物车、固定运费、跨店拆单 |
| 履约售后 | 模拟支付和物流，取消、付款、发货、收货、评价、退款和退货；商家处理、平台介入 |
| 资金 | 平台服务费率、创作者佣金、快照、退款调整、售后冻结、模拟结算和对账 |
| 广告 | 商家仅推广自有带货视频，按有效曝光计费，标识、预算、频控，不竞价 |
| 管理 | 审核、举报、下架、封禁、争议处理及操作记录 |

## 关键规则

- 订单始终归商品商家；创作者仅分佣。沿创作者链接购买才计佣，商城/搜索独立购买不追溯历史点击；商家自有商品不计佣。
- 平台费和佣金以不含运费的商品实付计算，均从商家收入扣除；买家支付结算页总额后不再额外收费。
- 下单保存商品、费用和来源快照；费率变更只影响新单，退款另记调整。
- 资金依据持久保存，不随作品删除、商品下架、账号隐私/封禁/注销消失；真实经营前另核实税务和法定留存要求。
- 私密账号关注需批准，已有粉丝保留，可移除粉丝。作品访问取账号和作品权限交集；好友指互关。
- 私密账号、好友可见和仅自己可见作品都不进入公开推荐、公开搜索和广告；直链及卡片不绕过权限；旧订单和佣金照常处理。
- 公开账号陌生人可发一条文字；私密账号仅批准粉丝可发首条文字。互关或已有双向会话可正常聊；单方历史不豁免。对方回复后解除首条限制。
- 客服入口豁免陌生人首条限制，拉黑仍禁止新消息；订单卡片不授予额外权限。
- 普通创作者收入只有成交佣金，无商家代投、创作费或广告分成。

## 技术与协作

单仓库 backend/frontend/android，Go + Hertz / React + TypeScript / Kotlin + Gradle；PostgreSQL 保留，现有版本基线为 17。Windows 11 开发，Ubuntu 26.04 LTS 运行，Docker Compose 优先。单机模块化单体，不引入 K8s、微服务、RPC 拆分或分布式技术。

推荐先用标签和行为统计的可解释规则；搜索使用 PostgreSQL。媒体 FFmpeg 异步处理、MP4 渐进播放、本机持久目录和受控访问，HLS 由测量决定。Android UI 可分阶段推进，每轮 API 消费验证不后置。

## 实施参数与后续范围

费率数值、广告单价/曝光阈值/频控、售后期、订单超时、媒体限制、舍入及性能目标在对应任务确定，不把默认值冒充已确认数值。微信/支付宝及真实物流在完整模拟验证后另行接入；真实提现、税务申报、竞价、多客服、群聊、音视频通话及复杂促销不在当前范围。
