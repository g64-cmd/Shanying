# Frontend

继承根 AGENTS.md。工作目录 .worktree/frontend，分支 dev/frontend，默认仅修改 frontend/。

- React + TypeScript，建议 Vite 构建；具体依赖版本在初始化应用时验证并锁定。旧 Vue 工程仅用于行为参考。
- 目录规划：src/app、src/features、src/shared、tests。服务端状态与播放/UI 状态分开。
- 所有请求通过统一 API 层；由 contracts/ 生成或校验类型，不手改生成文件，不私加字段或自行推断枚举。
- 短视频体验需覆盖播放/暂停、切换、加载失败、空列表、静音与浏览器自动播放限制；释放离屏播放器资源。
- 凭据处理遵循统一安全设计；刷新请求合并，失效后明确登录状态，不能无限重试。
- 页面包括未登录、加载、空态、错误和权限不足。键盘交互与基础可访问性纳入验收。
- 验证类型检查、生产构建、关键交互测试及真实浏览器行为；mock 通过不等于后端联调通过。
