# Tasks

本清单为待实施路线，规范完成不代表业务完成。每组同交共享 API、Go/TS/Kotlin 消费样例、测试及说明；Android UI 可分阶段推进。

## 1. 工程与契约

- [ ] 1.1 初始化 Hertz、PostgreSQL 迁移与单机 Compose；以 Ubuntu 构建、健康检查、空库迁移和重启持久化验证，记录锁定版本。
- [ ] 1.2 初始化 React/TypeScript 工程；以类型检查和生产构建验证，记录依赖版本。
- [ ] 1.3 初始化 Kotlin/Gradle 工程及 Wrapper；以编译和 JVM 样例解析验证，记录 JDK/SDK 要求。
- [ ] 1.4 建立 OpenAPI lint、样例校验及兼容检查；用不兼容样例验证检查可失败，记录三端生成/校验命令。

## 2. 账号与关系

- [ ] 2.1 定义身份契约和邮箱投递配置，实现注册验证、登录和找回；验证重复邮箱、过期/重放凭证及三端错误样例。
- [ ] 2.2 实现会话管理、刷新、撤销及资料编辑；验证旧凭据失效与客户端状态恢复，更新 API 文档。
- [ ] 2.3 实现关注审批、移除粉丝、隐私设置和黑名单；用已批准/待批准/被移除/拉黑矩阵及重复操作验证。

## 3. 媒体与发现

- [ ] 3.1 定义上传状态和样本限制，建立持久媒体任务；验证旋转、无音轨、损坏和超限样本以及进程重启恢复。
- [ ] 3.2 实现 FFmpeg MP4/封面及受控媒体访问；验证 Range、权限变化后的直链访问和失败清理，记录首帧及转码测量。
- [ ] 3.3 实现发布、删除、可见性及点赞评论收藏；验证账号/作品权限交集和重复写入，更新三端接口样例。
- [ ] 3.4 实现关注流与稳定分页；验证批准粉丝可见私密作品、非粉丝不可见及重复页处理。
- [ ] 3.5 实现反馈采集和规则推荐；验证冷启动、去重、负反馈、多样性及公开资格，记录排序参数和评估样例。
- [ ] 3.6 实现视频/用户搜索；用中文短关键词和隐私负向样例验证，商品/店铺搜索随商品模块补齐。
- [ ] 3.7 实现 Web 内容界面和 Android 消费端；验证浏览器播放/发布、移动端契约及必要设备播放，记录未完成 UI。

## 4. 通用私聊

- [ ] 4.1 定义消息/已读契约，实现持久消息、断线补拉和未读数；以重试/重连验证不重复消息和可靠确认。
- [ ] 4.2 实现消息权限及首条额度；覆盖公开陌生人、私密粉丝/非粉丝、单方/双向历史、互关及拉黑矩阵。
- [ ] 4.3 实现文字、图片、视频卡片及三端消费；验证资源权限、重试和错误展示，更新 API 说明。

## 5. 商家与订单

- [ ] 5.1 实现平台建店、商品 SKU/库存/固定运费契约及商家管理；验证商家隔离、上下架及非法配置。
- [ ] 5.2 实现商品/店铺搜索和商品推荐；验证中文查询、下架排除及视频关联商品优先。
- [ ] 5.3 实现购物车、地址、预览、跨店拆单及库存预占；验证总价、并发不超卖、取消释放及子订单归属。
- [ ] 5.4 实现视频挂链和服务端路径归因快照；验证商城重新购买不归因、逐商品归因及自有商品零佣金。
- [ ] 5.5 接入单店客服和商品/订单卡片；验证客服豁免首条但不豁免拉黑，普通接收者不能越权查订单。
- [ ] 5.6 实现 Web 购买/商家页面及 Kotlin 客户端；验证金额、跨店、重复提交和错误样例，更新操作说明。

## 6. 支付、履约与售后

- [ ] 6.1 固定状态机、超时及幂等契约，实现模拟支付创建/查询/关闭/通知；验证失败、重复、延迟和关闭后成功。
- [ ] 6.2 实现发货、模拟物流、收货和购买评价；验证分店独立履约、状态越级拒绝和评价权限。
- [ ] 6.3 固定售后期与退货退款契约，实现未发货退款、退货及部分退款；验证累计上限、重试及库存回补条件。
- [ ] 6.4 实现 Web 状态恢复及 Kotlin 消费测试；验证前端成功页不能确认付款，明确模拟标识并更新 API 文档。
